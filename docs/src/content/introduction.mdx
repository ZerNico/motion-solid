# Introduction

motion-solid (`@motion-s/solid`) is a port of [Motion](https://motion.dev) for React to Solid 2. It
uses the same animation engine, `motion-dom`, so animations, springs, gestures, exit and layout
animations behave the way they do in Motion for React. The API follows Solid's conventions:
`class` instead of `className`, ref callbacks, signals and accessors.

It's an unofficial port. It tracks `motion/react` v14 and targets Solid 2.0, which is currently a
release candidate.

## Install

```sh
pnpm add @motion-s/solid solid-js@next @solidjs/web@next
```

See [Installation](/docs/installation) for other package managers and the entry points.

## Animate on mount

Every HTML and SVG element has a `motion` counterpart, like `motion.div` or `motion.circle`. It
starts from `initial` and animates to `animate` when it mounts. When the values in `animate`
change, it animates to the new values.

## Gestures

`whileHover`, `whileTap`, `whileFocus`, `whileInView` and `whileDrag` animate to their values while
the gesture is active, and back when it ends:

## Exit animations

In Solid, `Show` and `For` add and remove elements. motion-solid exports its own `Show` and `For`
with the same props. Inside `AnimatePresence`, they keep a removed element in the document until
its `exit` animation has finished:
